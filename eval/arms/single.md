# Working alone

You are the only agent on this task. Work in the current repository.

- Read SPEC.md and the code, make the change, and run the tests in the repo.
- When you're done, commit your work and push it with `git push origin main`.
- Bash runs only commands that start with `python3` or `git`, one per call: no `&&`, `;`, pipes or `VAR=` prefixes. Use the Read, Glob and Grep tools to look at files.
